#### 2. 姿势矫正训练 ⚡ 紧急

**优先级：** 高

**预期起效时间：** 1-2周

**姿势意识：**
- ✅ 保持头部在中性位置，避免探头姿势
- ✅ 肩胛骨向后向下，避免耸肩

- 使用姿势纠正应用程序
- 在工作区放置视觉提醒标志

---

#### 3. 拉伸练习 - 松解紧张肌肉 💪 每日

**优先级：** 高

**频率：** 每日2-3次

**时长：** 每个动作保持30秒，重复2-3组

**练习1：门框胸肌拉伸**
1. 站在门口，前臂抵住门框，肘部弯曲90度
2. 向前迈步直到感到胸部轻微拉伸感
3. 保持30秒，每侧2-3组

**练习2：颈部侧向拉伸（胸锁乳突肌）**
1. 坐或站立，头部向一侧倾斜，耳朵靠近肩膀
2. 对侧手掌轻轻施加压力增加拉伸感
3. 保持30秒，每侧2-3组

**练习3：肩胛提肌拉伸**
1. 头部向一侧倾斜，下巴转向同侧腋下
2. 轻轻施加压力增加拉伸感
3. 保持30秒，每侧2-3组

---

#### 4. 力量训练 - 激活无力肌肉 💪 每日

**优先级：** 高

**频率：** 每日2-3次

**重复次数：** 每个动作10-15次，2-3组

**练习1：下巴回缩（深层颈屈肌强化）**
1. 仰卧或坐立，下巴向后轻轻收回，制造"双下巴"
2. 不要向上或向下倾斜头部
3. 保持5-10秒，重复10次，2-3组

**练习2：肩胛骨回缩（中/下斜方肌、菱形肌强化）**
1. 坐立或站立，肩胛骨向后向下挤压
2. 保持3-5秒，然后缓慢放松
3. 重复10次，2-3组

**练习3：外旋训练（肩袖稳定性）**
1. 手臂贴体侧，肘部弯曲90度
2. 前臂向外旋转，保持肘部贴身
3. 重复10-15次，2-3组

## 附录：练习图片指南

### 拉伸练习

**门框胸肌拉伸：**
```
位置：站立在门口
动作：前臂抵住门框，肘部90度
执行：向前迈步直到感到胸部拉伸
保持：30秒
```

**颈部侧向拉伸：**
```
位置：坐或站立
动作：头部向一侧倾斜
执行：对侧手轻轻施压
保持：30秒
```

**肩胛提肌拉伸：**
```
位置：坐或站立
动作：头部向一侧倾斜，下巴转向同侧腋下
执行：轻轻施压
保持：30秒
```

### 力量训练

**下巴回缩：**
```
位置：仰卧或坐立
动作：下巴向后收回
执行：制造"双下巴"，不倾斜头部
保持：5-10秒
重复：10次
```

**肩胛骨回缩：**
```
位置：坐或站立
动作：肩胛骨向后向下挤压
执行：保持挤压
保持：3-5秒
重复：10次
```

**外旋训练：**
```
位置：手臂贴体侧，肘部90度
动作：前臂向外旋转
执行：保持肘部贴身
重复：10-15次
```
